# Software Requirements
$ node -v
v24.18.1

$ npm -v
11.16.0

$ npm create vite@latest capstone_UI   
- install Vite
- select "React" as framework
- select "Typescript" as variant
- select "ESlist" as linter 
- run project with "npm run dev"
- go to "localhost:5173/" to view it locally
